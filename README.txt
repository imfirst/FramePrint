FramePrint — пакетная печать рамок AutoCAD в PDF / на принтер
=============================================================

Установщик (рекомендуется):
  1. Один раз собрать: powershell -ExecutionPolicy Bypass -File make_installer.ps1
     -> появится C:\FramePrint\FramePrint_Setup.exe
  2. FramePrint_Setup.exe (один файл, плагин внутри) можно запускать на любом компьютере с AutoCAD 2021–2024
     (двойной клик, права администратора не нужны).
  Удаление: Параметры Windows -> Приложения -> «FramePrint — пакетная печать рамок».

Сборка вручную (AutoCAD 2021–2024):
  powershell -ExecutionPolicy Bypass -File build.ps1
Установка с автозагрузкой:
  powershell -ExecutionPolicy Bypass -File install.ps1
Или разово в AutoCAD: NETLOAD -> bin\FramePrint.dll

Команды:
  FPRINT — окно: поиск рамок, таблица печати, PDF, печать, нумерация, ведомость, допуск СРО
  FPPDF  — без окна: найти рамки и сразу собрать PDF по текущим настройкам

Что перенесено из ваших настроек:
  - шаблоны Standart, PDF_a3_povorot, Принтер, PDF_поворот (активный);
  - слой FORMAT, масштаб 50, допуск 1 мм, сортировка Y-X;
  - штамп Форма 3: точки поиска (мм от правого нижнего угла рамки, радиус)
      номер листа 32;25;2  листов 15;25;2  наименование 90;12;6  шифр 65;55;2
    плюс атрибуты Лист / Листов / Наименование / Шифр;
  - PDF: папка «Документы», имя = имя файла, один многолистовой, открыть после,
    вектор 1200 / растр 400 dpi, шрифты включать;
  - ведомость: заголовок, столбцы 15/140/30, высоты строк и текста.

Допуск СРО:
  внизу окна — «Выбрать PDF…» (меняете раз в месяц), галочка и номер листа,
  после которого вставлять (1 = после титула). Многостраничный PDF вставляется целиком.
  Работает через временную PDF-подложку: в чертеже после публикации ничего не остаётся.
  Если файлу больше 35 дней — программа напомнит.

Настройки и шаблоны хранятся в %APPDATA%\FramePrint\settings.xml

Имя PDF: {Объект}_{Раздел}_{ДатаФайла}, например «Щукинская 3_О_2026-10-21.pdf».
  Раздел — последнее обозначение из списка О;ВК;ЭОМ;ВиК;СС;АР;ОВ;АПС;СОУЭ в шифре штампа
  первого по порядку листа крупнее A4. Список меняется в Настройки -> 5. PDF.
